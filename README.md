# 🔄 Renovapp: Gestor Automatizado de Renovaciones

> Sistema embebido en Google Sheets para el control integral y gestión de renovaciones de pólizas. Utiliza automatización nativa mediante secuencias de comandos para monitorear vencimientos y orquestar el envío de alertas automáticas a clientes y agentes, garantizando un índice de retención óptimo.

## 🛠️ Stack Tecnológico
* **Entorno Core:** Google Sheets (Base de datos y panel de control)
* **Motor Lógico:** Google Apps Script (ES6)
* **Automatización:** Time-driven Triggers (Monitoreo de vigencias)
* **Comunicaciones:** Gmail API (Distribución de alertas automatizadas)
